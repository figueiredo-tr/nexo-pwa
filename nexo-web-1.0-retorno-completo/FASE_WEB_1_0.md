# Fase Web 1.0 — retorno ao Nexo completo

Esta fase abandona a estratégia de interface PWA/mobile-first e volta a usar o renderer desktop completo como base funcional.

### Recuperado diretamente do desktop
- Visão Geral
- Movimentos com edição/exclusão
- Uber completo
- Cartões/faturas/parcelas/pagamentos
- Prioridades
- Investimentos e rendimentos
- Viagens com detalhes, itens e progresso
- Dívidas e pagamentos
- Calendário
- Relatórios
- Simulador
- Saídas
- Perfis
- Configurações

### Novo na versão web
- Sidebar responsiva para celular
- Supabase via navegador sem Electron
- Cache local via localStorage
- Gráfico de evolução financeira no dashboard
- Gráfico de saídas por categoria
- Cabeçalho de sincronização Supabase no lugar da conexão Google legada

O objetivo desta base é paridade funcional primeiro; refinamentos visuais podem ser feitos depois sem remover recursos.
